# 🛣️ Fuel Cost Calculator App

An interactive and user-friendly app to calculate fuel costs for your journey! 🚗⛽🗺️  
Plan your trips more efficiently by estimating fuel consumption and costs based on real-time fuel prices and route distances.

---

## ✨ Features

- **👋 Welcome Screen:**  
  A friendly introduction to get started with the app.

- **🚘 Vehicle & Fuel Consumption:**  
  Select your vehicle type (Car, Bike, etc.), and manually enter its fuel consumption (KM per liter).

- **⛽ Fuel Type & Real-Time Price:**  
  Choose your fuel type (Petrol, Diesel, etc.), and fetch real-time fuel prices using a free API.

- **🗺️ Journey Route:**  
  Select your start and end points on the map, and calculate the distance between them using the OpenRouteService API.

- **💡 Results & Calculation:**  
  View key metrics, including:
  - Fuel consumption efficiency
  - Distance between locations
  - Current fuel price
  - Calculated outputs:
    - Fuel cost (LKR)
    - Fuel required (liters)
